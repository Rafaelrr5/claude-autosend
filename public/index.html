Para usar outra pasta, edite o arquivo e abra o Claude Autosend de novo.

Primeiros passos — leia uma vez
  1. Não é um chat online. O Claude Autosend roda só neste computador. No horário marcado, ele entrega o seu texto ao Claude Code instalado aqui.
  2. Antes de tudo: instale o Claude Code e entre na sua conta nele uma vez, seguindo o guia oficial de instalação. Sem isso, nada é enviado.
  3. Deixe o computador ligado e acordado (sem suspender nem hibernar) até o horário. Fechar o navegador não desliga o programa; o botão Encerrar desliga. Para abrir de novo, clique duas vezes em Abrir-Claude-Autosend.
  4. Dois jeitos de enviar: New Claude session abre uma janela nova do Claude na pasta indicada acima. Existing window cola o texto numa janela do Claude que já está aberta — para isso o computador precisa estar desbloqueado e sem ninguém usando o teclado naquele momento.
  5. O Claude pode pausar e pedir sua permissão antes de agir. Isso é normal e protege seus arquivos; se você não estiver por perto, a tarefa espera por você. Este programa não desliga essas proteções.
  6. Um horário que passa com o programa fechado não é enviado depois.
